# Packages built against Armtix (aarch64) and Artix (x86_64) and published as
# one pacman repo per arch.
#
#   SOURCE NAME [ARCHES [OPTIONS]]
#                          ARCHES is a comma-separated list, default aarch64:
#                          almost everything here exists only because omarchy
#                          publishes no aarch64 build of it.
#                          OPTIONS: nocheck builds without the recipe's test
#                          step, for one whose tests need a package no repo
#                          here carries. Say why beside the entry.
#
#   omarchy NAME   pkgbuilds/NAME from omacom/omarchy-pkgs (branch master, latest
#                  at build time -- omarchy's own recipes, which already declare
#                  aarch64; omarchy just never publishes the aarch64 builds)
#   local NAME     pkgbuilds/NAME in this repo, for the rare recipe omarchy's
#                  cannot be built from here (see the recipe's header for why)
#   arch NAME      Arch Linux's official recipe (gitlab.archlinux.org/archlinux/
#                  packaging), with this arch added to arch=() -- for packages
#                  Armtix does not carry. Only recipes checked to be portable.
#
# No AUR. Every recipe is omarchy's, Arch's or ours, reviewed in this repo.
#
# ORDER IS BUILD ORDER: a recipe whose dependencies are built here must come
# after them (pinta after dotnet-core-bin).
#
# Only what the boxes cannot get elsewhere: on ARM, not in Armtix, not in
# omarchy's aarch64 repo, not an arch-independent package from its x86_64 repo;
# on x86_64, not in Artix and not in omarchy's repo.
omarchy asdcontrol
omarchy tzupdate
omarchy omasnap
omarchy omacalc
omarchy omacut
omarchy omawrite
omarchy cliamp
omarchy herdr
omarchy hyprland-preview-share-picker
omarchy dotnet-core-bin
omarchy pinta
local   localsend
local   wayland-pipewire-idle-inhibit aarch64,x86_64
# In omarchy's package list, in Artix's x86_64 repos, missing from Armtix.
arch    bluez-tools
arch    kernel-modules-hook
arch    nautilus-python

# carry (2026-10-11). The build itself needs only cargo.
